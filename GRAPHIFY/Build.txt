PROJECT OVERVIEW....
=================

GRAPHIFY is an AI-powered code analysis tool that:
* Analyzes source code in multiple programming languages
* Extracts code entities (classes, functions, imports, methods, variables)
* Generates interactive knowledge graphs showing code structure
* Provides beginner-friendly AI explanations (Claude or Mistral)
* Visualizes relationships between code components
* Exports analysis as JSON

Target Users: Beginners learning programming, students, developers exploring codebases

---

CORE FEATURES TO IMPLEMENT
============================

1. CODE INPUT
   ✓ Text area for code pasting
   ✓ File upload (.py, .js, .java, .html, .rs, .hol)
   ✓ Language selection (7 languages)
   ✓ Auto-detect language feature

2. CODE PARSING
   ✓ Parse Python (classes, functions, imports, decorators)
   ✓ Parse JavaScript (classes, functions, imports, arrow functions)

   • loading: boolean
   • error: string

2. GRAPHVISUALIZATION.JSX (React Flow Component)
   ──────────────────────────────────────────────
   Features:
   • Display nodes with custom styling
   • Display edges showing relationships
   • Allow zoom, pan, drag
   • Highlight on hover
   • Color nodes by type (class=pink, function=cyan, etc.)
   • Show tooltips on hover
   • Responsive to window size

   Node Types:
   • Class: Pink (#ec4899), rounded rectangle
   • Function: Cyan (#06b6d4), rectangle
   • Method: Amber (#f59e0b), square
   • Import: Purple (#8b5cf6), diamond
   • Struct: Green (#10b981), hexagon
   • Variable: Cyan (#0891b2), circle

   Edge Styling:
   • Solid line for inheritance
   • Dashed line for dependencies
   • Color-coded by relationship type

3. STATISTICSPANEL.JSX (Right Sidebar)
   ────────────────────────────────────
   Display:
   • Total Entities Count
   • Breakdown by Type:
     - Classes: X
     - Functions: X
     - Methods: X
     - Imports: X
     - Variables: X
     - Other: X
   • Language: [Detected/Selected]
   • Complexity Score
   • Lines of Code
   • Estimated Learning Difficulty

   Format: Cards with icons from Lucide

4. CODETPARSER.JS (Language Parsers)
   ──────────────────────────────────

   PYTHON Parser:
   ─────────────
   Extract using regex patterns:
   • Classes: pattern class ClassName
   • Functions: pattern def function_name
   • Methods: functions inside classes
   • Imports: import X, from X import Y
   • Decorators: @decorator syntax

   Return Structure:
   {
     entities: [
       { id: "ClassName", type: "class", name: "ClassName" },
       { id: "func1", type: "function", name: "func1" },
       { id: "import_pandas", type: "import", name: "pandas" }
     ],
     relationships: [
       { source: "ClassName", target: "method1", type: "contains" }
     ]
   }

   JAVASCRIPT Parser:
   ──────────────────
   Extract:
   • Classes: class ClassName
   • Functions: function name(), const name = (), arrow functions
   • Methods: methods inside classes
   • Imports: import X from 'Y', require('X')
   • Exports: export default, export const

   JAVA Parser:
   ────────────
   Extract:
   • Classes: class ClassName
   • Interfaces: interface InterfaceName
   • Methods: returnType methodName()
   • Constructors: ClassName()
   • Packages: package com.example

   HTML Parser:
   ────────────
   Extract:
   • Tags: <div>, <button>, <form>, etc.
   • IDs: id="elementId"
   • Classes: class="elementClass"
   • Attributes: onclick, data-*, etc.

   RUST Parser:
   ────────────
   Extract:
   • Structs: struct StructName
   • Enums: enum EnumName
   • Functions: fn function_name()
   • Implementations: impl TraitName for Struct
   • Use statements: use module::item

   HOLAND Parser:
   ──────────────
   Extract:
   • Programs: PROGRAM name
   • Procedures: PROCEDURE name
   • Variables: VAR name
   • Declarations: assignment statements

5. GRAPHUTILS.JS (Graph Generation)
   ─────────────────────────────────

   createNodesFromEntities(entities):
   • For each entity, create a node object
   • Assign unique ID
   • Set node type (class, function, import, etc.)
   • Assign color based on type
   • Set label to entity name
   • Return array of node objects

   createEdgesFromRelations(relationships):
   • For each relationship, create edge
   • Set source and target
   • Style based on relationship type
   • Set label if needed
   • Return array of edge objects

   calculateLayout(nodes, edges):
   • Use force-directed layout algorithm
   • Prevent node overlap
   • Organize by entity type
   • Return positions for each node

   generateStatistics(entities):
   • Count total entities
   • Count by type
   • Calculate complexity score
   • Return statistics object

   Color Coding Functions:
   • colorByType(entityType) → returns hex color
   • colorByLanguage(language) → returns hex color

6. STORE.JS (Zustand State Management)
   ────────────────────────────────────

   Create store with:
   • code: string (user input)
   • language: string (selected/detected)
   • entities: array (parsed entities)
   • graphData: {nodes, edges}
   • statistics: object
   • loading: boolean
   • error: string

   Actions:
   • setCode(code)
   • setLanguage(lang)
   • setGraphData(nodes, edges)
   • setStatistics(stats)
   • setLoading(bool)
   • setError(error)
   • reset()
